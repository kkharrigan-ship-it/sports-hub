# 19: Filters and search

**What to build:** Viewers narrow the Hub by category pills (All, Ice, Snow, Motor, Track & Other, Aquatics, Rugby) and by a search box that matches Sport, Event name, session or location. Filters apply to every view.

**Blocked by:** 16 (Hub skeleton)

**Status:** ready-for-agent

- [x] Category pills show their category icon. Icons appear only on pills, never in front of a Sport's name anywhere on the page.
- [x] Search is case-insensitive and updates as you type. With no matches, the page says so and offers to clear the filters.
- [x] Filters combine (category AND search) and apply to the Sports view, Timeline and "What's on".
- [x] It is checked in a browser preview with a fixed `data.json`.
